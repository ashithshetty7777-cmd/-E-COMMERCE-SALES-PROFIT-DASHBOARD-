# E-Commerce Sales & Profit Analysis Dashboard

## 📊 Project Overview

This project is an **E-Commerce Sales & Profit Analysis Dashboard** created using **Microsoft Excel**.

The dashboard analyzes sales, profit, quantity, orders, product performance, customer segments, regions, payment methods, and daily sales trends.

The goal of this project is to demonstrate practical **Data Analyst skills using Excel**, including data cleaning, formulas, Pivot Tables, Pivot Charts, slicers, and dashboard creation.

## 🧮 Excel Formulas Used

The project uses formulas such as:

* `SUM`
* `IFERROR`
* Multiplication and subtraction calculations
* Profit calculations
* Profit Margin calculations

### Key Calculations

**Gross Sale**

`Quantity × Unit Price`

**Net Sale**

`Gross Sale − Discount Amount`

**Profit**

`Net Sale − Product Cost − Shipping Cost`

**Profit Margin**

`Profit ÷ Net Sale`
